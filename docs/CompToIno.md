# CompToIno 2.0.0

Turn a `.cno` file into an Arduino `.ino`.

```bash
npx comptoino sketch.cno
```

Open the written `.ino` in the Arduino IDE and upload it.

```bash
CompToIno -h
CompToIno -v
CompToIno -d sketch.cno
```

The lesson is `docs/index.html`. It can be read in English, Portuguese, Spanish, and French.
