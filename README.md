# CompToIno
![JavaScript](https://shields.io) ![Arduino](https://shields.io) ![Version](https://shields.io)

A project that is for a programming language for Arduino.
It turn a `.cno` program file into an Arduino `.ino`.

## How to use
### Dependences
  - Node JS
  - NPM - it automatically installs NPX
### Using
It is really easy:
```bash
npx comptoino sketch.cno
```

Then, open the written `.ino` in the Arduino IDE and upload it.
Next update I am going to add auto-upload.
